# Классификация воображаемых движений по сигналам ЭЭГ

## Описание проекта

Проект посвящён классификации сигналов электроэнцефалографии (ЭЭГ) при воображаемом движении левой и правой руки (*Motor Imagery*).

В работе используется набор данных **EEG Motor Movement/Imagery Dataset** с платформы PhysioNet. Для эксперимента выбран первый испытуемый и записи runs 4, 8 и 12.

## Этапы работы

1. Загрузка исходных данных ЭЭГ.
2. Предварительная обработка сигналов с помощью библиотеки MNE: фильтрация в диапазоне 8–30 Гц и изменение частоты дискретизации.
3. Разделение сигналов на эпохи, соответствующие воображаемым движениям левой и правой руки.
4. Извлечение признаков с использованием метода Welch — логарифмической мощности сигнала в диапазонах mu (8–13 Гц), low beta (13–20 Гц) и high beta (20–30 Гц).
5. Обучение классификатора MLP (многослойный перцептрон) с использованием scikit-learn.
6. Оценка качества классификации с помощью метрик Accuracy, Balanced Accuracy, а также матрицы ошибок и других показателей.

## Используемые технологии

- Python
- MNE
- NumPy и SciPy
- scikit-learn
- Matplotlib
- Pandas

## Цель проекта

Проверить возможность автоматического распознавания воображаемых движений левой и правой руки на основе частотных характеристик сигналов ЭЭГ с использованием модели машинного обучения MLP.
